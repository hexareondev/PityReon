Перетащите сюда файл истории JSON в формате UIGF v4 — его делают выгрузчики истории круток. Файл читается прямо в браузере и никуда не отправляется.

Где взять файл истории?

Подойдёт любой выгрузчик с форматом UIGF v4 (например, StarDB или Starward). Или наш небольшой выгрузчик для Windows: он сам находит ссылку на историю в кэше игры, скачивает все баннеры Genshin Impact, Star Rail и ZZZ и сохраняет один файл uigf_*.json рядом с собой.

  1. Скачайте gacha_export.exe и положите в любую папку — устанавливать ничего не нужно.
  2. В игре откройте историю круток — так в кэше появится свежая ссылка.
  3. Запустите exe двойным щелчком и дождитесь надписи «Готово».
  4. Перетащите получившийся файл сюда. В следующий раз выгрузчик докачает только новые крутки.

Windows может предупредить «Система Windows защитила ваш компьютер»: у программы нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае». Exe собирается автоматически на серверах GitHub из открытого кода этого репозитория, обращается только к официальному API истории круток и ничего не меняет в файлах игры.

Сборки берутся из витрины профиля через Enka.Network — в игре выставьте агентов в витрину. Каждая загрузка сохраняется, так что со временем здесь копятся все агенты, которых вы показывали.

Браузер не пустил запрос к Enka напрямую. Есть два способа:
  1. Откройте ответ Enka по вашему UID, сохраните страницу (Ctrl+S, как .json) и загрузите её кнопкой «Загрузить файл».
  2. Один раз заведите бесплатного посредника на Cloudflare — код и инструкция в tools/enka-proxy-worker.js — и укажите его адрес в настройках. Тогда кнопка будет работать сама.

Пул проигрыша 50/50

По этому списку размечаются 50/50: если на ивентовом баннере выпал предмет из пула проигрыша, 50/50 проигран. Пул проигрыша — это стандартный пул плюс лимитированные, которые игра со временем добавляет только в проигрыш. Дата «с» — с какого дня предмет может так выпасть: выпадения до неё считаются выигрышем. Правки хранятся у вас и попадают в резервную копию.
